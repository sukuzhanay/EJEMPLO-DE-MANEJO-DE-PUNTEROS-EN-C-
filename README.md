# Punteros y direcciones en C++

Ejemplo docente de direcciones de memoria, desreferenciación y punteros a punteros.

## Scope

El programa imprime un puntero antes de inicializarlo; esa operación no debe tomarse como una práctica correcta. El ejercicio requiere revisión antes de usarlo como ejemplo de código seguro.
